Architecture & scope

Python → persona database identities → Oracle 26ai Free. A SQL property graph connects issuers, LEI entities, instruments, positions, portfolios and desks. Oracle computes every embedding. OAMP 26.8.0 stores extracted preferences under isolated desk schemas. SQL workload mining preserves metric lineage to V$SQL. Both agents use the same selected model; the naive agent is never scripted to make a mistake.

The browser’s persona switch is for a trusted laptop demo. Group trees are fictional, modelled on GLEIF Level 2 parent/child relationships. Synthetic market data are for demonstration. No investment decisions are executed.
