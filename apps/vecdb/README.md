# Sample Apps

This directory hosts VecDB sample applications demonstrating how to build AI-powered experiences on Oracle AI Database (VecDB). Each entry links directly to the app folder so you can dive into its README and source code.

| Title | Stack | Highlights | Path |
| ----- | ----- | ---------- | ---- |
| Doc Chatbot | Streamlit, Oracle VecDB, OpenAI/Ollama | Upload documents, embed them, and chat with retrieval-augmented answers citing source chunks. | [Open](./doc_chatbot) |
| Fashion Product Search | FastAPI, React, Oracle VecDB, Transformers | Multimodal search over product catalog images and descriptions with metadata filtering and streaming assets. | [Open](./fashion_products_search) |
| Product Recommendation | FastAPI, React, Oracle VecDB, CLIP | Semantic search and recommendation flow for catalog items with pricing filters and CLIP embeddings. | [Open](./product_recommendation) |
| Semantic Code Search | FastAPI, React, Oracle VecDB, Jina Embeddings | Index Python repositories and explore relevant code via similarity search with expandable context panes. | [Open](./semantic_code_search) |
| Ask the Parks | Python, Oracle VecDB, Leaflet | Semantic National Park Service search with city/radius and GeoJSON QBE filters, map results, and park details. | [Open](./vecdb_ask_parks) |

Looking for notebook tutorials instead? Jump to the [Sample Notebooks](../../notebooks/vecdb) collection.
